# 鉴赏方法：感情的回溯性重构

## 一句话

逐句猜感情，带着前文重猜；读完全部，让每段产生的新感情把旧感情「容纳」进来——不是否认旧判断，是重构。

## 三阶段

1. **逐句猜**：每读一句先猜「此刻的感情」。
2. **带前文重猜**：下一句连同上文一起猜，允许改判；改判要记「因为哪句」。
3. **回溯重构**：读完回头，把每次改判的「表层」与「底层」分层——旧判断不死，成为新判断的地基。

## 矛盾为什么是重点

- 单段读出一个判断，多段读会互相矛盾（例：轻 vs 怕、浮着 vs 沉没）。
- 矛盾不是错误，是**支点**：矛盾让判断成立，让读者感到「舒服的刺激」——被击中，又不被说服得太快。
- 所以不要急着消除矛盾，要记录它在哪一段被第几句/第几帧激起。

## 与「否认」的区别

| 否认 | 重构 |
|---|---|
| 旧判断是错的，丢掉 | 旧判断是表层，容纳进新判断 |
| 一次通读下结论 | 逐段读，每段改判 |
| 结束于结论 | 结束于「可证伪」 |

## 可证伪

每次重构后的判断都要写：**什么证据会让这次判断也倒？**
没有可证伪的鉴赏，只是标签。

## 落盘格式（示例）

```text
### S3 60–97s｜荒诞：把悲伤写成病症
带着：她拒绝治愈，用自嘲挡
转写：15-17 巨浪/凉透、18-20 太阳/晒干这片蓝、23-29 老中医/湿气/沙漠皮
画面：65s 侧躺、83s 背坐远景
曲调：80s↑ 上行 → 95s↓
猜：病症化是「把疼说成可治的」，越荒诞越安全；65s 躺下不是沉底，是浮着
改判：「侧躺=沉没」被推翻，改判「浮着」
```
